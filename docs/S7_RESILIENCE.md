# 입력 오류, 편집 초점, 문서와 연결의 보존

**잘못된 입력은 고칠 곳을 알려 주고, 선택한 작업은 같은 내용으로 이어져야 합니다.**
S7은 실제 제작·읽기 경로에서 재현한 문제를 보완합니다. 기존 이름과 입력 형식,
출처·관계·시간의 의미는 [디자인 기준](FOUNDATIONS.md)과 [제작·읽기 흐름](S6_FLOWS.md)을 따릅니다.

## 1. 키보드로 고른 모듈에서 편집 이어가기

제작실의 모듈 목록에서 키보드로 항목을 선택하면 해당 모듈의 속성 편집으로 초점을 이어 줍니다.
목록을 다시 그리면서 방금 사용한 버튼이 사라지는 경우에도 다음 조작 대상을 잃지 않게 합니다.
기존 라이브러리 삽입의 초점 이동 규칙을 재사용하며, 포인터 선택에는 새 초점 이동을 강제하지 않습니다.
canvas에서 선택한 대상과 기존 스크롤·선택 ID는 그대로 유지합니다.

## 2. 입력 오류를 해당 필드에서 설명하기

라이브러리와 제작실의 요소 입력은 기존 native 범위와 정규화 규칙을 따릅니다.
잘못된 값은 현재 문서나 마지막 유효한 미리보기에 반영하지 않고, 어떤 필드를 고쳐야 하는지
문장으로 안내합니다. 오류를 표시하는 필드는 `aria-invalid`와 설명 연결을 함께 사용합니다.
기존 도움말 연결을 보존하고, 값을 올바르게 고치면 해당 오류를 해제합니다.

오류가 발생했는데 이전의 성공 문구가 현재 결과처럼 남지 않게 합니다. 같은 오류 안내를
반복 입력마다 새로 발표하거나, 입력 중 초점을 강제로 옮기지 않습니다. 별도의 입력 형식이나
검증 모델을 만들지 않고 기존 native control과 `CVA_ELEMENTS.normalize`가 유효성을 결정합니다.

## 3. 파일 이름과 내용은 같은 문서를 가리키기

Board에서 HTML 파일을 준비하는 동안 다른 문서를 가져올 수 있습니다. 파일의 내용과 이름은
저장을 시작할 때 캡처한 같은 문서를 기준으로 합니다. 준비가 끝난 순간 화면에서 선택된
다른 문서의 이름을 가져다 쓰지 않습니다.

이전에 요청한 유효한 문서 사본의 다운로드는 유지하되, 오래된 작업의 완료 메시지가 새 문서의
가져오기 안내를 덮어쓰지 않게 합니다. 기존 요청 순서와 닫기 처리를 사용합니다. 다운로드 요청을
디스크 저장 완료로 표현하지 않습니다. 편집 파일 JSON에도 같은 파일 이름 기준을 적용합니다.

가져오기 적용 후에는 새 문서의 제목 입력으로, 취소 후에는 파일 선택 입력으로 초점을 옮깁니다.
숨긴 확인 영역에 초점이 남지 않도록 기존 dialog 안의 보이는 조작 대상으로 이어 줍니다.

### 파일을 읽지 못했을 때 · #5814 후속

선택한 파일의 내용을 읽지 못하면 파일 위치·접근 권한을 확인하고 다시 선택하도록 한국어로
안내합니다. 현재 문서와 읽기 위치는 유지하며, 실패한 최신 파일 선택만 비워 재선택할 수 있게 합니다.
이전 요청의 늦은 실패는 새로 선택한 파일과 검토 안내를 덮어쓰지 않습니다.

이 안내는 `File.text()` 읽기 실패에만 적용합니다. JSON 해석과 문서 형식·내용 검사는 기존 경로와
구체적인 오류 안내를 유지합니다. 안내 개선과 브라우저의 실제 파일 전달·저장 성공은 별도로 확인합니다.

## 4. 같은 장면으로 돌아가는 관계

Story의 기존 계약은 `return`이 같은 장면 또는 앞선 장면으로 돌아가는 것을 허용합니다.
Board도 같은 관계를 받아들이며, 이미 있는 자기 복귀 루프 경로를 사용합니다. 원래 입력의
관계를 삭제하거나 다른 관계로 바꾸지 않습니다. 잘못된 목적지·중복 연결·허용되지 않는 관계·
순방향 관계의 잘못된 순서는 기존 검사로 계속 거절합니다.

초점 보기의 그룹은 **들어오는 연결 / 지금 고른 장면 / 나가는 연결**로 읽습니다.
들어오는 연결의 출발점이 반드시 시간상 앞선 장면인 것은 아니므로, 연결 방향을 시간 순서로
설명하지 않습니다. 선택한 장면은 가운데 한 번만 표시하며, 자기 복귀는 그 장면의 관계로 남깁니다.
기존 배치·선 경로·카메라 알고리즘과 저장 형식은 바꾸지 않습니다.

## 5. 정본과 확인 경계

| 범위 | 정본 | 기존 계약 |
| --- | --- | --- |
| 라이브러리·제작실 | `cva/library.*`, `cva/studio.*` | native 입력·정규화, 선택·되돌리기, 마지막 유효 문서 |
| Board 관계 | `tools/elio_board/app/vendor/board-model.js`, `projection.js` | 기존 Story return 의미, 목적지·조건·읽는 순서 |
| Board 파일·가져오기 | `tools/elio_board/app/authoring-ui.js` | 캡처한 문서, 요청 순서, 기존 adapter·독립 HTML |
| Board 배포 사본 | 기존 builder의 `board/`와 manifest | 정본 파일 지문과 버전 URL 일치 |

입력 오류→수정, 키보드/포인터 선택, HTML 준비 중 문서 교체, 가져오기 적용·취소,
기존 자기 복귀 입력의 내보내기·재열기를 실제 함수와 adapter로 확인합니다.
이 검사는 전체 브라우저 bootstrap이나 실제 디스크 저장을 뜻하지 않습니다.

브라우저 렌더·실제 키보드 초점·화면 넘침·확대·보조 기술과 사용자 과제 검증은 별도 증거가
필요합니다. S7의 코드 보완과 그 실행 검증을 구분하고, 미확인 항목은
[후속 기록 #5814](https://github.com/ttaem00/chzz-vod-analyzer/issues/5814)에 유지합니다.
독립 Story 예제의 작품 홈 배포 상대경로 정책도 이번 Board 수정과 별도로 추적합니다.

- [W3C Focus Order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html): 의미와 조작을 유지하는 초점 이동 순서. 특정한 초점 목적지는 기존 Elio 패턴에 맞춘 구현 결정입니다.

이 문서는 확인한 소스 동작과 구현 결정을 설명하며, WCAG 준수 인증이나 사용자 테스트 완료를 주장하지 않습니다.
