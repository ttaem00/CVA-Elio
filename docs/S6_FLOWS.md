# Elio 제작과 읽기 흐름

**만들 결과를 고르고, 지금 편집하는 대상을 확인하고, 필요한 파일로 이어갑니다.**
이 문서는 S6에서 정돈한 실제 라이브러리·제작실·Story·Board의 사용 기준입니다.
확정한 제품 이름과 기존 입력·출처·관계·시간 계약을 그대로 따릅니다.

[라이브러리](../cva/library.html) · [페이지 제작실](../cva/index.html) · [Story 예제](../examples/story.html) · [Board](../board/index.html) · [디자인 기준](FOUNDATIONS.md)

## 1. 만들 결과에서 시작하기

라이브러리 첫 화면은 **무엇을 만들까요?**로 시작합니다. 기존 세 시작 구성에서
예제를 살펴보거나 바로 제작실로 이동할 수 있습니다.

| 행동 | 실제 이동 | 유지되는 정보 |
| --- | --- | --- |
| 예제 살펴보기 | 해당 구성의 상세 설명·실제 미리보기 | 선택한 구성, 분류·검색과 스타일 문맥 |
| 이 구성으로 만들기 | 새 탭의 실제 페이지 제작실 | 구성과 지원하는 스타일·팔레트 선택 |
| 결과물 스타일·색상 | 필요한 경우 펼치는 선택 영역 | 여덟 profile과 네 palette의 기존 ID |
| 분류·검색 | 필요한 요소·모듈을 더 자세히 찾기 | 기존 검색·분류·상세·뒤로 가기 경로 |

시작 카드는 미리보기와 만들기를 별도 링크로 제공합니다. 카드 전체 링크 안에 또 다른
링크를 넣지 않습니다. 상세 화면과 잘못된 항목 경로에서는 첫 화면의 시작 구성을 숨기고,
기존 탐색 경로로 돌아오면 그 상태에 맞게 다시 보여 줍니다.

## 2. 지금 편집하는 대상 알기

제작실은 문서 제목과 함께 **페이지 전체** 또는 **선택한 모듈 · 순번 / 전체**를 표시합니다.
속성 패널을 닫아도 작업 영역에서 현재 대상을 확인할 수 있습니다. 대상 이름을 바꾸거나
모듈을 삭제·복원하면 기존 선택 상태를 기준으로 안내도 함께 갱신합니다.

**결과물 스타일**은 만드는 페이지에 적용합니다. 편집 도구의 외관과 출력 페이지의
profile은 [디자인 기준](FOUNDATIONS.md#1-작업-화면과-만드는-페이지)의 역할 구분을 따릅니다.
스타일 변경으로 내용·순서·관계·출처를 만들거나 바꾸지 않습니다.

현재 대상의 이름에는 사용자가 입력한 문장을 안전하게 표시합니다. 화면 안내를 위해 별도의
선택 모델이나 저장 형식을 추가하지 않습니다.

## 3. 파일의 목적을 먼저 고르기

제작실의 **파일로 저장**에서 두 결과를 구분합니다.

| 원하는 결과 | 형식 | 실제 단계 |
| --- | --- | --- |
| 열어 볼 페이지 | HTML | 현재 페이지와 필요한 자원 준비 → HTML 다운로드 |
| 다시 편집할 파일 | JSON | 현재 구성 준비 → JSON 다운로드 → 나중에 편집 파일 열기 |

파일을 준비하는 일, 다운로드를 요청하는 일, 브라우저가 디스크에 저장하는 일은 서로 다른
단계입니다. 화면은 확인할 수 있는 준비·요청 상태를 안내합니다. Object URL을 만들거나
다운로드 링크를 눌렀다는 이유로 **저장 완료** 또는 자동 저장을 표시하지 않습니다.

- 내용이 바뀌면 이전에 준비한 다운로드는 무효화됩니다.
- HTML 준비 중 내용이 바뀌면 오래된 결과를 다운로드로 노출하지 않습니다.
- 실패하면 현재 내용을 유지하고 다시 준비할 수 있습니다.
- JSON을 다시 열 때는 기존 크기 제한·입력 정규화·미리보기 확인을 거친 뒤 현재 페이지에 적용합니다.
- 준비된 미리보기와 현재 가져오기 요청이 일치해야 적용할 수 있습니다. 적용 후 기존 되돌리기를 사용할 수 있습니다.

이 규칙은 기존 exporter·revision·Object URL 정리·가져오기 계약을 사용합니다.
사용자 파일이나 브라우저 권한을 새 방식으로 처리하지 않습니다.

## 4. 장면·항목을 읽고 돌아오기

Story의 일반·장면 카드 보기에서 장면 이동 영역은 현재 장면과 이전·다음을 가시적인 말로 안내합니다.
이 영역의 버튼과 현재 장면 링크에는 44px 이상의 최소 높이를 선언하고, 기존 장면 ID·비활성 상태·분기 선택·스포일러 처리를 유지합니다.
사진 흐름 보기에서 사용하는 별도의 이동 UI는 기존 동작을 따릅니다.
아직 드러내면 안 되는 장면 제목을 새 접근성 이름이나 툴팁으로 노출하지 않습니다.

Board에서는 **이야기의 장면**과 **도감의 항목**을 구분해 선택·미리보기·복귀 목적지를
안내합니다. 명시된 되돌아가는 관계는 이어지는 연결과 구분합니다. 영향·전달·순서·복귀의
목적지와 조건을 보존하며, 가까이 배치되었다는 이유로 연결이나 인과를 만들지 않습니다.

Board에서 문서에 변경을 적용하는 행동과 편집 파일·페이지 파일을 내려받는 행동도 구분합니다.
Board의 독립 HTML은 기존처럼 문서를 포함해 다시 읽고 편집할 수 있습니다. 제작실의
조합 페이지 HTML과 각 도구의 재편집 계약을 혼동하지 않습니다.

근거를 읽은 뒤 관련 장면으로 이동하거나 읽기 화면을 닫아 원래 선택으로 돌아가는 기능은
기존 controller가 소유합니다. 선택·카메라·포커스 복귀와 안전한 출처 링크 처리를 보존합니다.

## 5. 정본과 생성물

| 화면 | 수정할 정본 | 동기화할 결과 |
| --- | --- | --- |
| 라이브러리·제작실 | `cva/library.*`, `cva/index.html`, `cva/studio.*` | 실제 진입 화면과 기존 controller |
| Story 읽기 | `tools/elio_preview/`의 template·style·장면 안내 | 기존 renderer가 생성한 Story 예제 |
| 제작실의 Story 표현 | 같은 원형 template·style·scene shell | `scripts/build_elio_reader.py`가 생성하는 canonical reader 구역 |
| Board | `tools/elio_board/app/` | 기존 builder의 `board/`, 버전 URL과 `build-manifest.json` |

생성된 HTML이나 배포 사본만 고치지 않습니다. 이미 있는 입력과 builder로 생성하고,
정본·배포물·기록된 파일 지문이 함께 맞는지 확인합니다. 읽는 순서, 작품 속 시간,
원본 영상 시각, 편집 결과 시각은 [네 시간 기준](FOUNDATIONS.md#5-네-시간-기준과-관계의-의미)을 따릅니다.

## 6. 확인해야 할 흐름

첫 구성 선택 → 실제 제작실 → 대상 선택·제목 변경 → 파일 준비·다운로드 → JSON 다시 열기를
같은 내용으로 확인합니다. Story·Board에서는 현재 선택 → 연결·근거 확인 → 원래 위치로 복귀를 확인합니다.

기존 API·내보내기·재열기 검증과 변경된 controller의 구체적인 계약, 정본 생성 결과,
Python 로컬 서버의 응답·참조를 검사합니다. 실제 브라우저의 글자 배치·키보드·화면 넘침·
다운로드 권한은 별도의 관찰이 필요합니다. 소스나 HTTP 검사만으로 시각·접근성 검수를
완료했다고 표시하지 않습니다.
