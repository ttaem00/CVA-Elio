2026-10-30 공개 소스의 해당 페이지를 기준으로 확인했으며, 가상의 UI·별도 시안·합성 화면으로 대체하지 않았습니다.

기억 테이프·달의 기억은 앞선 실제 제품 검증에서 촬영하고 원본 bytes로 보관한 캡처입니다.
이번 README 작업에서 동일한 공개 원본 페이지의 유지 여부와 캡처 구도를 다시 확인했습니다.
관계도·해설·라이브러리는 이번에 같은 공개 소스를 로컬 서버에서 열어 촬영했습니다.
WebP는 브라우저가 직접 출력한 이미지이며 제품 화면의 내용을 재작성하거나 합성하지 않았습니다.

선택 기준은 제목·본문·근거의 가독성, 전체 노드와 연결선, 로딩 완료, 화면 끝의 잘림과 불필요한 여백입니다.
오른쪽 귀환 노드가 잘린 관계도 캡처와 다음 해설 제목이 어색하게 걸친 캡처는 채택하지 않았습니다.
창작 데모의 지도·해설은 실제 작품의 대표 이미지로 사용하지 않습니다.

명조: 워더링 웨이브는 KURO GAMES의 작품이며, 제휴 작품·인물·이미지·영상·모델의 권리는 각 원래 권리자에게 있습니다.
스크린샷의 공개가 제3자 자산에 CVA 소프트웨어 라이선스를 부여하지는 않습니다.
