이 페이지의 피드백과 라이브러리는 같은 상태 처리 함수와 CSS를 사용합니다. 위의 문장 복사는 실제 클립보드 작업이고, 실패 체험만 명시적인 시뮬레이션입니다. 정적 상태 카드는 실행 결과가 아닌 표현 예시입니다.

진행·완료·실패 모두 실제 문장을 제공하며, 기호와 색은 읽기를 돕습니다. 움직임 줄이기 설정에서는 진행 표식도 정지합니다.

행동 기호는 기존 Lucide 고정 버전의 경로를 그대로 사용합니다. 출처·사용권 고지 · 브랜드와 상태 사용 기준
