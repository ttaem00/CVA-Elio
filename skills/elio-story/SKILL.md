# Elio Story

[패키지 안내](../../README.md)와 [이야기 저작 기준](../../docs/STORY_AUTHORING.md)을 읽는다.
`examples/`는 입력 형식을 보여 주는 창작 예제이며 실제 작품의 사건·인용·이미지 근거가 아니다.

작품·판본/버전·다룰 구간과 독자가 알 수 있는 범위를 확인한다. 장·회차·장면·페이지·패널은
원매체의 위치이며 특정 게임의 막·퀘스트 체계로 바꾸지 않는다. 실제 원문을 읽고 사건 ID와
출처를 연결한다. 매체별 위치를 기존 `source_lines`에 문자나 시간값으로 끼워 넣지 않는다.
위치 기록과 현재 계약에 맞추는 방법은 저작 기준을 따른다.

본편은 독자가 공개받는 순서를 유지한다. 작품 속 연대, 인과·의존, 인물의 지식·관점,
선택에 따른 실제 대안은 서로 다른 관계다. 필요한 것만 기존 `reader_guides`,
`story_topology`, `time_map`으로 작성하며 회상·불확실한 증언·반복을 같은 것으로 처리하지 않는다.
게임의 분기·수치·진행 조건은 해당 작품과 출처가 확인될 때만 다룬다.
다시보기는 선택 사항이다. 영상이 없는 책·만화에도 방송·스트리머·시계를 만들지 않는다.

기존 renderer로 새 파일을 만든다. 연결할 영상이 없으면 `--connections`를 생략할 수 있다.

```text
python scripts/render_story.py --input STORY.json --source SOURCE.json --output NEW.html
```

검증한 같은 장면의 다시보기가 있으면 `--connections CONNECTIONS.json`을 더한다.
이미지 권리·실제 인용·확인한 사실과 해석·미확인을 구분하고, 실제 브라우저에서 본편·관점·
원문·복귀와 재열기를 확인한다. `board/index.html`과 명시적 JSON 입력의 Board 빌드는
같은 이야기나 도감을 보드로 읽는 별도 경로다. 자동 매체 변환·원문 수집·번역·이미지 관리
서버는 제공하지 않는다. 기존 입력 계약을 바꾸거나 없는 importer를 가정하지 않는다.

로컬 저장과 웹 게시는 별개다. 공개에는 정확한 결과물·권리 범위·사용자의 별도 결정이 필요하다.
