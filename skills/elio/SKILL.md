# Elio

[패키지 안내](../../README.md)와 [이용 정책](../../POLICY.md)을 먼저 읽는다.
`design/tokens.js`, `design/components.js`, `design/cva.css`의 기존 API와
8개 profile·4개 palette, 안전한 링크·plain text escape를 보존한다.

이야기 조사·해석·장면·관점 저작은 [Elio Story](../elio-story/SKILL.md)를 사용한다.
게임의 장·퀘스트, 영상의 회차·장면, 책의 장·페이지, 만화의 화·패널을 모두
작품의 구간과 출처 위치로 읽는다. 특정 작품의 이름·세계관·색·수치·진행 조건을
다른 자료의 기본값으로 옮기지 않는다. 공개 순서·연대·인과·관점은 별도로 정한다.

페이지·보드의 표현은 실제 내용의 순서·비교·소속·분기·관계에 맞춰 고른다.
`cva/library.html`에서 지원 입력을 찾고 `cva/index.html`에서 편집한다.
`board/index.html`의 자체 Board는 명시한 이야기·도감 입력을 사용한다.
[자체 표현 안내](../../docs/OWNED_RUNTIME.md)에서 정확한 지원 ID·입력·한계를 확인한다.
원래 Forma·Aceternity 구현이 동봉된 것으로 가정하지 않는다.

입력·관계·출처를 실제 자료로 작성하고 새 파일로 렌더한 뒤, 실제 브라우저에서
읽기·탐색·복귀와 보관본의 재열기를 확인한다. 설치·웹 게시·외부 AI 전송은
스킬 호출만으로 실행하지 않으며 부재 기능·작품 근거를 만들지 않는다.

원본 템플릿을 요청받으면 실제 renderer·공용 DOM·CSS·입력 계약에서 재사용 경로를
추적한다. 이름·색 profile만 바꾼 별도 모듈을 원본 재사용의 증거로 삼지 않는다.
전체 원형 목록을 Library의 실제 미리보기·저작 입력·독립 출력과 대조해 누락을 확인한다.
공개 패키지는 원본 전체 자료실과 shared-source 재생성 검사를 사용한다. 제한된 자산을
교체할 때는 원래 템플릿과 데이터 관계를 보존하고 교체 범위를 명시한다.

공용 스킬의 매체 범용성과 기존 작품 예제의 보존은 별개다. 특정 작품에 과적합하지
말라는 요청을 기존 완성본·내용·연출을 삭제하거나 임의 대체하는 권한으로 해석하지 않는다.
